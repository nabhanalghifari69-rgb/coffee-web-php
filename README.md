# coffee-web-php
Website coffee shop berbasis PHP, HTML, CSS dan bootstrap dengan tampilan responsif
# COFFE'IN

Website coffee shop berbasis PHP.
Dibuat sebagai tugas kuliah Sistem Informasi, Universitas Bina Sarana Informatika.

## Fitur
- Daftar menu dan harga
- Informasi kontak
- Pemesanan melalui halaman kontak, terhubung dengan nomor meja dan dikirim ke WhatsApp admin

## Halaman
Beranda, Menu, About, Event, Kontak

## Teknologi
PHP, HTML, CSS, Bootstrap

## Cara Menjalankan
1. Pindahkan folder proyek ke C:\laragon\www
2. Jalankan Apache di Laragon
3. Buka http://localhost/coffe%20web/

## Catatan
Nomor WhatsApp admin diganti placeholder (628XXXXXXXXXX).
Ganti dengan nomor asli di pages/kontak.php agar fitur pemesanan berfungsi.
